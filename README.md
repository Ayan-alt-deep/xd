# Eren's Image Upload API

This is an API that allows users to upload images to Eren's custom server by sending an image URL. It uses the **Imgbb API** to host the image and returns a direct URL of the uploaded image.

## Features:
- Upload images to Eren's custom server.
- Simple and easy-to-use API.
- Returns a direct URL of the uploaded image.
- Supports image upload via a URL (from reply or attachment).
